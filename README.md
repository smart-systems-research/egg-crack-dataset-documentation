# Dataset Information: Ensemble Deep Learning for Egg Quality Assessment

Supplementary dataset information for the paper:

> Ransarani, T., Wedasingha, N., & Kavalchuk, I. *An image-processing-based ensemble deep learning framework for non-intrusive egg quality assessment and smart food packaging applications.* Discover Artificial Intelligence (under revision).
>
> Preprint: https://doi.org/10.21203/rs.3.rs-10517617/v1

| File | Contents |
|---|---|
| `Dataset Summary.xlsx` | Total images, class balance, and train/validation and test split counts |
| `Dataset Sources.xlsx` | The public datasets the images were drawn from, with owners, source URLs and images used per class |
| `Annotation Protocol.xlsx` | Class definitions and the annotation and curation procedure |

Each file is also provided as a `.csv` with the same content, so it can be viewed directly in the browser.

The images themselves are not included here; they come from the public datasets listed in `Dataset Sources.xlsx`.
